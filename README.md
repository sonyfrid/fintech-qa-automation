## 📋 Описание проекта

Проект демонстрирует профессиональный подход к автоматизации тестирования финансового приложения **Parabank** — специального банковского приложения для практики тестирования.

### 🌐 Тестируемый ресурс

| Параметр | Значение |
|----------|----------|
| **Сайт** | [Parabank](https://parabank.parasoft.com) |
| **Тип** | Банковское приложение (демо) |
| **Компания** | Parasoft |
| **Назначение** | Платформа для обучения тестированию |

### ✨ Особенности проекта

- ✅ **E2E тестирование** пользовательских сценариев
- ✅ **API тестирование** банковских операций
- ✅ **Page Object Pattern** для поддерживаемости кода
- ✅ **Типобезопасность** с TypeScript
- ✅ **CI/CD** для автоматического запуска тестов
- ✅ **Отчёты** с видео, скриншотами и трейсами

## 🚀 Быстрый старт

### Предварительные требования

- Node.js 18+
- npm 9+
- Git
--- 
### Установка

```bash
# Клонировать репозиторий
git clone https://github.com/sonyfrid/fintech-qa-automation.git

# Перейти в папку проекта
cd fintech-qa-automation

# Установить зависимости
npm install

# Установить браузеры Playwright
npx playwright install

# Все тесты
npm test

# С браузером (видеть, что происходит)
npm run test:headed

# С отладкой
npm run test:debug

# Открыть HTML отчёт
npm run report
```

│

## 📊 Пример отчёта

После каждого запуска тестов автоматически создаётся HTML-отчёт с подробной информацией о результатах.

---

### 📈 Общая статистика

- **Пройденные тесты** — зелёные, успешные сценарии
- **Упавшие тесты** — красные, с описанием ошибки
- **Пропущенные тесты** — жёлтые, пропущенные по условию
- **Общее время выполнения** — сколько занял весь прогон
- **Процент успешности** — соотношение passed/failed

---

### 🎬 Медиа-материалы

| Материал | Описание |
|----------|----------|
| 📹 **Видео** | Запись прохождения каждого теста |
| 📸 **Скриншоты** | Автоматически сохраняются при падении |
| 🔍 **Трейсы** | Полная история действий для отладки |

---

### 🔍 Детализация

- **Пошаговое выполнение** — каждый шаг теста с описанием
- **Значения селекторов** — какие элементы использовались
- **Ожидаемые vs фактические** — что должно было быть и что получилось
